# Local one-click workflow

1. `npm run dev`, or `npm run build` followed by `npm run start -- -p 3002`. Open `/personalize?section=excel-formation`. The existing Next standalone warning concerns deployment packaging; no hosting changes were made.
2. Select an `.xlsx`. Read/profile/detect run through the existing worker. The original stays local. The action is enabled only when the primary mapping is valid; ambiguous/missing required mappings must be resolved first.
3. Click **Tự động sửa Excel** in the header. A dialog shows **Verified-only**, real stages, rows, supported changes, unresolved cells and elapsed time. The existing suggestion layout stays in place beneath the dialog.
4. The app generates and downloads `originalname.repaired.xlsx` and `originalname.repair-report.json` as local Blobs. If the browser blocks multiple downloads, use **Tải lại Excel** and **Tải báo cáo sửa** in the result dialog. A partial result is labelled **Đã sửa một phần — vẫn cần rà soát**; it is not called clean or JSON-ready.
5. **Hủy** requests cancellation at the next worker checkpoint. Patching and package verification may delay acknowledgement. Cancellation or verification failure commits nothing and offers no output. Review → **Undo** reverses the entire automatic batch; **Redo** restores it. **Save progress** can preserve work after a sensitive-data confirmation; **Resume progress** checks the original file and replays the changes.
6. Use existing review suggestions/manual editing for unresolved values. The normal JSON flow still requires all safety checks, including duplicate-value conflicts, unmapped/secondary-sheet corruption, metadata and exact mapping. Claude's concurrent JSON update adds explicit file-naming and template-order checks to the original nine (eleven checks in the combined tree). Creating a partial XLSX never unlocks JSON by itself.

The app must load first; this feature does not install an offline PWA. Once the page, worker and workbook are loaded, repair/download work offline. No server Queue action is needed. Clicking **Save original to server Queue** is an explicit upload of the whole original; that separate feature uses the existing server authentication/retention policy.

Excel preservation means original sheet layout, styles, formats, formulas, names, filters, panes, merges and unrelated package entries are kept. Supported text patches preserve all known characters and digits. Unsupported rich text, merged/formula-dependent cells and ambiguous characters remain unchanged and are reported. Desktop Excel checks in the validation document cover synthetic fixtures, not arbitrary private workbooks.
