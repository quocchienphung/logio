Get started

Use it in your project

Four steps from install to loading states. The README covers every prop, theming, and use without React.

Read the docs on GitHub →
  1. 01

    Install

    Add the package from npm, or straight from GitHub. React 17 or newer is all it needs.

    npm i ascii-reveal

# or straight from GitHub
npm i github:quanhoangindex/ascii-reveal
  2. 02

    Wrap your content

    Everything inside decodes into place when it mounts: text, images, canvases and video.

    import { AsciiReveal } from 'ascii-reveal';

<AsciiReveal preset="decode">
  <YourPage />
</AsciiReveal>
  3. 03

    Mark the pieces

    Optional attributes for cards, buttons, and anything that should stay untouched.

    <article data-ascii="surface">…</article>
<button data-ascii="fade">Buy</button>
<nav data-ascii="skip">…</nav>
  4. 04

    Show loading states

    An ASCII skeleton paints instantly while data loads, then the real content decodes in. Use AsciiSkeleton on its own if you only want the placeholder.

    import { AsciiReveal, AsciiSkeleton } from 'ascii-reveal';

<AsciiReveal loading={!data}>
  {data
    ? <Stats data={data} />
    : <AsciiSkeleton variant="dither" />}
</AsciiReveal>
