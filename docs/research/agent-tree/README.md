# Agent Tree — analysis of the public preview

Source: https://www.affectui.com/components/agent-tree (public preview and docs only). The Pro source, the host API and the CLI were **not** used; everything was rebuilt from the observed preview (`source-*.png`, `source-preview.html`, `observed-rules.css`, `sequence.json`, `windows.json`, `source-docs.txt`).

## What was observed

- A status bar (title, counts: running / needs you / failed, cost total) with windows that list the blocks that need a decision (Approve/Reject) or failed (Retry/Dismiss).
- A tree of cards, 216px wide, 32px indent; side-by-side children when there is room (≥ 560px), indented when not. Connectors are drawn from the measured card positions: a bus with rounded child corners (wide) or hang elbows (narrow); one dot per parent.
- Card: avatar/brand mark, name, model, status glyph, task text, tool marks, cost and time; fold buttons collapse a branch (the card shows what is hidden); a removed card fades out in place; moves glide (FLIP).
- Costs roll up; a failed try stays as its own card when retried.

## What was built

`src/components/sites/affectui-agent-tree/`: `tree-model.ts` (+tests) pure model; `AgentTree.tsx`, `agent-bar.tsx`, `agent-card.tsx`, `tree-marks.tsx`, `agent-tree.css` (`--agt-*` tokens, dark mode). Adaptations: card width shrinks to ≥ 168px so the side-by-side layout also fits a laptop with a side panel; `badge` (role) and `renderCardActions` slots; `idle` status (“Ready”) for a plan that has not run.

The Process page uses these cards in two views: the **Map** (cards placed freely by `ProcessMap`, joined by curves) and the **Tree**.

## Brand marks

`ai-marks.generated.ts` is generated by `scripts/forensics/agent-tree-ai-marks.mjs` from `@lobehub/icons-static-svg@1.95.1` (MIT): 88 marks (Kimi, Codex, Claude Code, Qwen, DeepSeek, Mistral, Ollama, Hermes Agent and 80 more coding agents, agent frameworks, models, runtimes and clouds; the list is in `process/agent-roster.ts`). Each file is checked (drawing elements, gradients, masks and filters only; no scripts, links or styles); one that fails is skipped, not patched. A contact sheet of all marks in both themes was checked by eye; Kimi's white ink is drawn in the text color so it shows on a light card, and a few dark-on-dark marks are lifted in dark mode. Anthropic, OpenAI, Gemini and the tool marks come from the earlier affectUI-derived set (`docs/research/agent-lanes/extra-lanes.md`).

## Not covered

Pro-only code and any state not visible in the public preview. Timings and easing are measured from the preview, not copied from source.
