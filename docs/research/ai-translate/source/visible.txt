When to use
Messages, comments, reviews or support tickets written in another language, translated on demand inside the product.
Release notes or announcements that readers in several regions open in their own language.
Any place you want an AI translation to feel inline and reversible, with the original one click away.
When not to use
Translating a whole page or app interface; use your i18n framework.
Long documents with headings and lists; this renders one plain paragraph.
Live captions or speech; use a realtime stream component.

API reference
AiTranslate

An inline translator for one message or paragraph. A byline with a detected language chip sits above the text; below it, a Translate picker (English, Deutsch, Français, Español, 日本語, Português), a Show original toggle and a status line credited to the model's mark. Picking a language dims the text on screen and streams the translation in place in fast chunks, each new sentence retiring one sentence of the old text, while the card's height springs to fit. Finished translations are cached, so Show original and switching back crossfade instantly. Failures put the previous text back and show Couldn't translate with Retry.

Accessibility
The card is a section named after the author. The paragraph carries the lang attribute of the language on screen, and dimmed old sentences keep their own lang, so screen readers pronounce both correctly.
Start, completion, the original and failures are announced in a polite status region; the paragraph is aria-busy while it streams. The simulation says that nothing was sent.
The language menu is a radio group with a checkmark on the current language. The Show original toggle is a pressed button whose label switches to Show translation.
Status is never color alone: the model mark plus a label (Translating to German, Translated from French, Showing original), or a warning icon plus Couldn't translate.
Every control is at least 32px tall, and labels reserve the width of their longest version, so nothing moves under the pointer.
Motion
Streaming: chunks of 3 to 6 words (about 10 characters in Japanese) land every 34ms and only fade in over 140ms. No blur, slide or per word spring.
The text on screen dims to 45% over 200ms as translating starts, and each sentence that starts in the new language removes one dimmed sentence, so the translation replaces the paragraph sentence by sentence.
Cached translations and the original swap with one crossfade: the old text leaves in 100ms, the new one fades in over 160ms with a 2px rise.
The paragraph's height follows its text with a critically damped spring (visualDuration 0.24, no bounce); window resizes cut straight to the new height.
Status labels crossfade in one shared cell; the picker and toggle labels crossfade inside their reserved width. The menu fades and scales from 98% in 150ms.
Reduced motion keeps every end state and announcement but drops chunk fades, crossfades and the height spring, and autoplay runs once.
Responsive behavior
The card fills its container up to 620px and pads 16px on phones.
Below a 470px card width the status line drops under the controls, left-aligned with the text; below 380px the chip shows just the language name.
Names and meta truncate with an ellipsis; the paragraph wraps with text-wrap: pretty. No horizontal scroll at 360px.
Performance
Chunks append as spans with a CSS fade, so streaming re-renders one paragraph and never animates layout.
One ResizeObserver drives the height spring; autoplay pauses through an IntersectionObserver while the card is off screen.
Every request owns an AbortController; switching language or unmounting cancels the network call and timers.
Notes for AI

Give your coding assistant the Markdown reference instead of screenshots.

Wire translate to your model. Return an async generator of deltas to stream real tokens, or a Promise<string> and the component streams it in chunks itself. Always pass the signal to fetch.
Cache lives per instance and per text; a new text prop clears it. Persist translations yourself (onTranslate) if you want them across sessions, then pass them back in translations.
Use the source language as value to show the original. Show original remembers the last translated language for Show translation.
Keep one paragraph or message per instance. For a whole thread, render one AiTranslate per message and control value from a shared preferred language.
Model names in samples must be current: Claude Haiku 5.5 is the default credit; swap the mark and name for your provider.
Sentence splitting keeps decimals like 4.2 whole and handles 。！？ for Japanese.
