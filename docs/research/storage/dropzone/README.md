## Evidence and measurements

Per-state JSON records element geometry and computed style; `observed-rules.css` contains only public rendered CSS observations, never imported by the implementation.

At 1440px viewport the source card is 520px wide, capped at 520px, with 10px corners, a fine ring/shadow, an 8px inset and a 44px footer. The empty card is 198px tall. Text uses Inter 13/20, medium titles, 12/16 metadata. The three document sheets occupy 64×44px. Their left/right transforms are translate(±12px, 2px) rotate(±10°) at rest and translate(±28px, 0) rotate(±16°) during drag, with a 420ms cubic-bezier(.22,1,.36,1) transition. The center sheet lifts 8px, scales to 1.05, and its upload arrow bobs every 900ms. Drag changes the dashed outline and wash to blue; row progress is a 2px blue line, completion adds a small green check, errors use red metadata plus a short shake, and removal folds the row. The footer shimmers during active work. Reduced motion removes these transitions/animations. Source touch CSS increases controls from 28px to 36px and the footer from 44px to 52px.

## Local adaptation

Implementation: `src/components/sites/storage/StorageDropzone.tsx` and `storage-dropzone.css`. Entry status and actual progress are controlled by the page. `progress` is a percentage from 0 to 100; the component never advances it on a timer. It shows queue/processing state rather than an invented upload transfer or time estimate. Pending files say “queued,” support Clear, and do not shimmer; only actual processing shimmers. `onFiles` receives native files; the parent owns validation, extraction and persistence. Accepted picker extensions: PDF, DOCX, TXT, MD, CSV, TSV, SQL, JSON, XLSX. The hint reflects the existing 20MB limit instead of the source demo's 25MB limit. The second fanning badge reads SQL to fit the knowledge-library content. Empty state has no sample files.

All visible controls are real: native picker, drop target, parent-supplied retry, removal and Clear. Native button semantics provide Enter/Space; focus rings are visible; a polite live region announces completed/error outcomes. File-name ellipsis leaves room for row actions. No network calls occur in this component. CSS is scoped to `.storage-dropzone` and supports `.dark` / `[data-theme="dark"]` ancestors.
